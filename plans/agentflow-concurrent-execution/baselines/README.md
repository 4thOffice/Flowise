# Agentflow V2 Concurrent Execution — Baseline Regression Suite

Regression suite of 6 zero-API-key Agentflow V2 flows (local nodes only: `startAgentflow`, `customFunctionAgentflow`, `conditionAgentflow`, `directReplyAgentflow`, `humanInputAgentflow`, `loopAgentflow`), captured once on **unmodified `master`** (before) and replayed on the concurrent scheduler (after), both against a locally built server with an isolated SQLite database.

- **Before Captured At**: `2026-11-19T14:29:28Z` (unmodified `master`) — [`traces/before/summary.json`](./traces/before/summary.json)
- **After Captured At**: `2026-11-21T01:47:27Z` (`feat/agentflow-concurrent-execution` + Task 07, `AGENTFLOW_MAX_NODE_CONCURRENCY=10`) — [`traces/after/summary.json`](./traces/after/summary.json)
- **Sequential Parity Captured At**: `2026-11-21T01:47:52Z` (same build, `AGENTFLOW_MAX_NODE_CONCURRENCY=1`) — [`traces/after/concurrency-1/summary.json`](./traces/after/concurrency-1/summary.json)
- **Capture Script**: [`capture-traces.mjs`](./capture-traces.mjs)

Durations are single wall-clock runs measured by the capture script (HTTP round trip including SQLite persistence); SSE offsets come from the `nextAgentFlow` frames recorded on the wire.

## 3. Reproducing / Re-Running Traces (`before` or `after`)

Build the workspace (`pnpm build`), then start Flowise with an isolated database directory (leaving `~/.flowise` untouched):

```bash
mkdir -p /tmp/flowise-baseline-db/{storage,logs}
DATABASE_PATH=/tmp/flowise-baseline-db \
SECRETKEY_PATH=/tmp/flowise-baseline-db \
BLOB_STORAGE_PATH=/tmp/flowise-baseline-db/storage \
LOG_PATH=/tmp/flowise-baseline-db/logs \
PORT=3000 \
bash -c 'cd packages/server/bin && ./run start'
```

Run the capture script (defaults to `traces/before`; pass `--out-dir` for the after replays):

```bash
# Baseline (unmodified master)
node plans/agentflow-concurrent-execution/baselines/capture-traces.mjs

# After replay (concurrent scheduler, default AGENTFLOW_MAX_NODE_CONCURRENCY=10)
node plans/agentflow-concurrent-execution/baselines/capture-traces.mjs \
  --out-dir plans/agentflow-concurrent-execution/baselines/traces/after

# Sequential parity: restart the server above with AGENTFLOW_MAX_NODE_CONCURRENCY=1, then
node plans/agentflow-concurrent-execution/baselines/capture-traces.mjs \
  --out-dir plans/agentflow-concurrent-execution/baselines/traces/after/concurrency-1
```
