## Summary

1. **Headline, S01 at turn 5 (M1)**: 48.7 KB raw / 16,068 base64 characters before, **1,073 bytes raw / 664 base64 characters** after (2.15 % of the raw JSON), with the same ten history messages.
2. **The token is the history.** Every token is 221–1,548 bytes raw on finished and failed turns (268–1,136 base64 characters) and 900–2,079 bytes on paused turns (680–1,128), against 43.7–300.8 KB raw (14,524–83,988 base64 characters) before. On finished turns the history is 55–94 % of the raw JSON; the rest is field names, flow state and form values, plus S12's child token.
3. **A turn adds its own messages and nothing else** (sections B and C). Over the 70 pairs of consecutive turns that are not paused, `Δ raw` equals `Δ history` in 57. The other 13 are changes the flow makes: S03's flow state (+7, −11, −47 B) and S11's (+5, −10 B), S05's new form values (+1 B), and S12's child token (+28 to +72 B per turn). On the 67 turns that append a user message and a reply, `Δ history` is exactly the bytes of those two messages.
4. **Size goals** (`SIZE-token-v2`, checked in [10-after-vs-before.md](./10-after-vs-before.md)): the largest share of `before/` is 3.62 % (S06 M2 t4, a paused token); on finished turns 3.18 % (S12 M1 t4, child token included) and at most 2.50 % elsewhere. S13 has no `before/` token; its largest token is 482 bytes (limit 4 KB).
5. **Paused tokens** (section D): 680–1,128 base64 characters instead of 15,192–53,400. `pendingResume` is 577–1,548 bytes: the skeleton (2–7 entries), the slim action of each stopped node (279–344 B), the stop prompts (51–242 B per token) and, for an Agent tool approval, the checkpoint (402–416 B: the tool-call message and history references). No system prompt: 0 sentinels in every paused token.
6. **Child flow tokens** (section E): S12's child token is 300–444 base64 characters inside the parent token, with 2–8 child history messages and no prompt once decoded. The parent token stays at 1.6–3.2 % of `before/`.
7. **Client payloads** (section F): external executed data is 282 B–1.9 KB per turn instead of 41.8–295.8 KB, with no prompt; the `action` is 279–341 B instead of 366 B–43.1 KB; S13's JSON response is 954 B instead of 44.0 KB. The internal chat keeps full records (M1-internal S01 44.4 KB, S07 45.1 KB with one prompt, the Agent's own input; before, a stop repeated it in the action).
